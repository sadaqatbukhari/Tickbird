## Tickbird 1.4.1

Insert, edit and delete records straight from a query result.

### New
- **Actions menu on query results**: when a result comes from a plain `SELECT ... FROM table` (no joins, grouping or aggregates), an **Actions** button
  above the grid offers **Insert Record…**, **Edit Record…** and **Delete Record…**. The same commands are in the right-click menu.
  Nothing is sent until you confirm: the confirmation shows the record, or each change as *old → new*, and a delete says it cannot be undone.
  The query runs again afterwards so the grid shows what is stored.
- **TimescaleDB and CrateDB**: a record is found by the table's primary key (by all columns when there is none). If more than one row matches,
  nothing is changed. CrateDB changes are refreshed so they show at once.
- **InfluxDB 1.x**: insert points, change field values and delete points. A point's time and tags identify it, so they cannot be edited.
- **InfluxDB 3.x**: insert and edit (it has no delete statement, so Delete is not offered).
