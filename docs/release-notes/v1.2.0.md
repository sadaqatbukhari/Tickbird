## Tickbird 1.2.0

A usability release focused on working with several query tabs.

### New
- **Ctrl+Tab tab switcher**, like Visual Studio: hold Ctrl and press Tab (or Shift+Tab) to cycle through the open
  tabs, most recently used first, and release Ctrl to switch. Ctrl+PageUp / Ctrl+PageDown move to the neighbouring tab.
- **Unsaved changes prompt**: closing a query tab (✕, Close All, Close All But This) or the application with edited
  queries now asks to **Save**, **Don't Save** or **Cancel**.
- **Show Column as Date/Time**: right-click a result column to display epoch values (seconds to nanoseconds) as
  dates, using your date format.

### Improved
- New toolbar icons for **Comment**, **Uncomment** and **New Query**; New Query now shows its text next to the icon.
- Epoch-precision query results are formatted as date/time when the column is shown as time.
