## Tickbird 1.3.0

Tickbird now works with **TimescaleDB** and **CrateDB**, next to InfluxDB 1.x and 3.x.

### New
- **TimescaleDB**: browse databases, hypertables, text and other columns, chunks, retention policies, continuous aggregates,
  backfill, roles and privileges, running queries, diagnostics and statistics, with the same tools as InfluxDB.
- **CrateDB** (over its PostgreSQL protocol): tables in all schemas, columns, partitions, users and privileges, running jobs,
  and node, shard and health statistics.
- **A connection dialog that follows the database**: the port, sign-in fields and notes change with your choice. For CrateDB it
  leaves out the Database field, starts with the `crate` user and refuses the HTTP port 4200.
- **A toolbar that follows the connection**: commands the selected database cannot do are hidden, and tooltips use its own words
  (Text Columns, Partitions, Delete All Rows...).
- **Help guides** for [TimescaleDB](https://github.com/sadaqatbukhari/Tickbird/blob/master/docs/help/timescaledb.md) and
  [CrateDB](https://github.com/sadaqatbukhari/Tickbird/blob/master/docs/help/cratedb.md), with tested query cookbooks and sample data.
- A warranty and liability notice in **About** and in the documentation.

### Fixed
- The query editor kept its scrollbar out of reach when the results area was resized; the editor now fits its space and can always be scrolled.
- Values written as text now fit numeric and timestamp columns on PostgreSQL-family databases, and a lost connection during an action is reported instead of crashing.
